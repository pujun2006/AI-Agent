**智能体的安全与权限越权（AI Agent Security & Privilege Escalation / Unauthorized Access）**是指智能体在感知环境、推理决策并调用工具或访问系统的过程中，由于**指令劫持、身份与权限边界模糊、过度授权或执行环境隔离不足**，导致其执行非预期操作、突破访问控制限制、泄露敏感数据或破坏系统状态的安全风险。

与传统“只读文本生成”的大模型应用不同，智能体往往同时具备**自然语言理解能力**与**真实世界动作执行能力**（如查库、写文件、发邮件、调内部 API、执行代码）。一旦攻击者操纵其决策，或系统赋予智能体的权限超出了当前用户或当前任务应有的边界，就会发生权限越权或安全事故。

## 一、 什么是智能体中的“权限越权”？

在智能体系统中，**权限越权**通常指智能体突破了**用户身份边界、任务最小权限边界或工具调用边界**，具体表现为两类典型情况：

1. **水平越权（跨用户 / 跨租户越权）**：普通权限用户通过对话或工具调用，诱导智能体读取或修改属于其他用户、其他部门或其他租户的私有数据（如他人订单、客户记录、内部文档）。
2. **垂直越权（低权限主体触发高权限动作）**：
* 低权限用户借助智能体拥有的“高特权服务账号（Service Account）”或“全量工具集”，间接执行了自己本身无权执行的操作（如批量导出数据、修改权限、删除记录、触发支付或发送对外通知）。
* 或者智能体在正常交互中，被诱导调用超出当前任务所需的敏感工具。

## 二、 导致安全问题与权限越权的常见成因

### 1. 提示词注入（直接注入与间接注入）

* **直接提示词注入**：用户输入中夹带覆盖系统规则的指令，试图绕过限制或诱导越权操作。
* **间接提示词注入**：恶意指令潜藏在外部数据源中——例如网页内容、邮件正文、PDF/知识库文档、工单描述或工具返回结果。智能体在检索或汇总这些“不可信数据”时，可能把数据里的攻击指令误当作高优先级控制指令执行。

### 2. 过度授权与“共享特权凭证”

* 许多早期实现直接用一个拥有高权限的 API Key、数据库账号或系统令牌来运行智能体，而**没有将发起请求的人类用户身份（User Context / OAuth Token）透传并做细粒度鉴权**。
* 结果是：哪怕提问者只是普通员工，智能体也可能凭借“替身特权”触碰管理员级资源。

### 3. 指令与数据边界混杂（Control-Data Confusion）

* 大语言模型在上下文中接收到的系统提示词、用户指令、历史记录以及外部检索/工具输出，本质上都是 Token 序列。若缺乏严格的输入隔离、结构化校验和动作层鉴权，恶意数据就可能劫持控制流。

### 4. 工具与执行环境缺乏沙箱与隔离

* 若智能体可直接读写宿主机文件系统、执行未受限的 Shell/Python 代码、访问内网元数据服务或直接调用无二次确认的写接口，一旦发生误判或被劫持，后果将直接落到真实环境上。

## 三、 典型安全风险与攻击场景

* **敏感数据外泄（Data Exfiltration）**：智能体被诱导读取机密文档、隐私信息（PII）或内部凭证后，通过发邮件、发消息、写外部链接或构造特定参数把数据带出。
* **越权读写与状态篡改（Unauthorized State Mutation）**：被诱导修改数据库记录、覆盖文件、更改配置或执行不可逆操作（如删除数据、对外发送通知）。
* **工具滥用与“混淆代理人（Confused Deputy）”问题**：智能体作为拥有工具权限的中间代理人，被外部不可信输入“忽悠”去滥用自身合法权限。
* **代码与系统级破坏**：代码解释器缺乏隔离时，可能出现越权访问目录、耗尽资源或横向探测内网的问题。

## 四、 如何防范安全风险与权限越权？

防范智能体安全与权限越权，不能只靠在 System Prompt 里写一句“请遵守安全规范、不要越权”，而必须建立纵深防御（Defense in Depth）体系：

图中展示了最小权限原则（Principle of Least Privilege, PoLP）的核心思想：主体仅被授予完成特定功能所必需的最小权限——可以访问授权资源，但对受限数据明确拒绝。

| 防护层级 | 关键工程措施 | 核心作用 |
| --- | --- | --- |
| **身份与权限隔离** | 落实最小权限原则；按**实际发起用户身份**做鉴权（而非盲目使用高权限全局凭证）；按任务/角色动态挂载工具集 | 从源头上限制智能体能触及的数据与接口范围 |
| **动作门禁与人工审批** | 对写操作、删除、外发、资金/权限变更等高危动作设置硬性拦截或人在回路（Human-in-the-Loop）确认 | 即使模型决策被误导，关键外部动作仍需经过安全校验或人工放行 |
| **输入输出护栏与数据清洗** | 对外部检索/网页/邮件等不可信内容做隔离与提示词注入检测；对输出做敏感信息（PII / 密钥）脱敏与 Schema 校验 | 降低恶意指令劫持与敏感数据外传的概率 |
| **沙箱与网络隔离** | 代码执行与浏览器自动化放入隔离沙箱（如容器/微虚拟机），限制文件系统挂载、系统调用与外网访问 | 把潜在失控或越权行为关在隔离边界内，缩小爆炸半径 |
| **审计日志与异常监控** | 完整记录每次工具调用的身份、参数、目标资源与执行结果，对高频敏感查询或异常外联告警 | 支持事后溯源、权限审计与快速止损 |
