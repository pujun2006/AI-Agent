Market data and customer analysis are executed in parallel.py代码利用 LCEL 的 `RunnableParallel` 与 Python 的 `asyncio` 异步机制，实现了一个“并行分析 + 汇总整合”的投资顾问工作流。市场趋势分析与客户画像分析会并发执行，以缩短整体等待时间，最后再将两路结果合并生成综合建议。

---

### 一、 核心组件与执行流程

整个流程分为初始化、双路并行子链、扇出/扇入编排与异步调用四个阶段：

1. **环境与模型初始化**
* `load_dotenv()` 读取 `.env` 中的 `LLM_MODEL_ID` 和 `LLM_API_KEY`。
* `ChatTongyi` 初始化通义千问模型（默认 `qwen-max`），`temperature=0.3` 兼顾分析条理性与适度表达灵活性。


2. **两条独立分析子链（`market_data_chain` 与 `client_analysis_chain`）**
* **市场分析链：** 接收 `market_data`，提炼市场趋势。
* **客户分析链：** 接收 `client_data`，分析投资偏好与风险承受能力。
* 两条链互不依赖，各自走 `PromptTemplate | llm | StrOutputParser()` 流程，非常适合并行执行。


3. **并行编排与汇总整合（`parallel_analysis_chain` 与 `full_workflow_chain`）**
* `RunnableParallel({"market_analysis": market_data_chain, "client_analysis": client_analysis_chain})` 会把同一个输入字典同时分发给两个分支，并收集各自输出组装为 `{"market_analysis": ..., "client_analysis": ...}`。
* `full_workflow_chain` 在并行层之后接上 `summary_prompt | llm | StrOutputParser()`，形成典型的扇出（Fan-out）→ 扇入（Fan-in）结构，把双路分析结果合并为一份投资顾问建议。


4. **异步执行主函数（`run_async_pipeline`）**
* 通过 `await ...ainvoke(input_data)` 异步触发执行，由 `asyncio.run(...)` 启动事件循环。
* 演示了两种调用方式：
* **方式 A：** 仅运行 `parallel_analysis_chain.ainvoke(...)`，直接查看两份独立分析结果。
* **方式 B：** 运行 `full_workflow_chain.ainvoke(...)`，走完“双路并发分析 → 综合报告生成”全链路。

### 三、 潜在风险与改进点

* **方式 A 与方式 B 存在重复计算：** 在当前 `run_async_pipeline()` 中，`parallel_analysis_chain` 先跑了一遍，随后 `full_workflow_chain` 又重新执行了一遍并行分析与汇总。若只需要最终报告，直接调用 `full_workflow_chain.ainvoke(...)` 即可；若两者都需要，可复用 `parallel_results` 的结果传入后续汇总链，避免双倍 Token 与耗时开销。
* **外部调用缺乏超时与异常隔离：** 并行分支涉及网络请求与大模型推理，建议为外部调用配置超时控制，并在多任务并发时考虑单路失败的降级或报错处理。
* **多余导入与提示词风控：** 代码中导入了 `RunnablePassthrough` 但未实际使用；此外涉及投资建议场景，实际业务中通常还需在系统提示词或报告末尾补充风险提示与合规免责声明。
