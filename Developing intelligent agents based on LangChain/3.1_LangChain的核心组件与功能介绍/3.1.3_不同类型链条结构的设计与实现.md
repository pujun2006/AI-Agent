LangChain 的链式结构以 `Runnable` 统一执行契约为底座，围绕数据流向与控制复杂度演化出多种拓扑形态。现代架构以 LCEL（LangChain 表达式语言）为核心编排层，并在需要状态循环与多轮决策时平滑升级至基于 LangGraph 的图状态机运行时。

---

## 一、底层抽象：从传统类继承到 LCEL 组合原语

早期 LangChain 依赖面向对象的继承体系封装固定流程（现已归入 `langchain-classic` 兼容包），现代架构则完全建立在 **`Runnable` 协议**之上。任何组件只要实现统一的同步、异步、流式与批量调用接口，即可作为独立节点参与拓扑拼接，并在组合阶段完成输入输出类型的自动校验与类型强制转换。

---

## 二、常见链条结构的设计与实现机制

### 1. 线性串行链（`RunnableSequence`）

* **拓扑设计：** 单向管道结构，数据沿节点序列依次流转，前驱节点的输出直接映射为后继节点的输入，呈现经典的“输入处理 → 模型推理 → 结构化解析”流水线。
* **底层实现：** 内部维护有序的 `Runnable` 节点列表。执行时按序调度各节点，并具备**端到端流式传播机制**——一旦下游节点（如输出解析器）支持增量消费，上游模型的首字 Token 即可直接穿透整条链路输出，极大降低首字延迟。

### 2. 并行扇出与聚合链（`RunnableParallel`）

* **拓扑设计：** 一对多扇出再汇合的菱形拓扑。同一份输入同时分发给多个相互独立的子链，所有分支完成后将其输出聚合为统一的键值映射字典。
* **底层实现：** 同步调用时利用线程池并发执行各分支，异步调用时通过事件循环协程并行调度，整体耗时取决于执行最慢的单个分支而非所有分支之和，常用于多路检索召回与多维度并行分析。

### 3. 上下文透传与增量赋值链（`RunnablePassthrough` / `RunnableAssign`）

* **拓扑设计：** 旁路保留结构。在多步加工过程中，既对部分字段进行变换，又原封不动地向后传递原始输入，避免中间转换丢失关键上下文信息。
* **底层实现：** 本质上是并行结构的特化变体。它将数据流拆分为“原样直通分支”与“转换加工分支”，随后将新生成的键值对合并回原始字典中，确保下游节点同时获得原始请求与中间产物。

### 4. 条件路由分支链（`RunnableBranch`）

* **拓扑设计：** 动态多路选择结构（类似程序中的多分支条件判断），先由轻量分类器或规则函数评估输入特征，再将请求导向最匹配的专用子链。
* **底层实现：** 内部维护一组“条件谓词函数 + 目标子链”的有序配对及一个默认兜底链。运行时自上而下依次求值谓词，命中首个为真的条件后立即激活对应子链并短路跳过其余分支。

### 5. 弹性容错与降级链（`RunnableWithFallbacks` / `RunnableRetry`）

* **拓扑设计：** 主备冗余结构。主执行链外层包裹重试策略与备用模型/备用子链，应对模型限流、网络抖动或格式解析失败。
* **底层实现：** 通过装饰器模式包装原 `Runnable` 节点。当主节点抛出指定异常且耗尽退避重试次数后，调度器自动将相同输入无缝切换至备选节点重放，对上层调用方保持输出接口完全一致。

### 6. 检索增强与记忆状态链（RAG & Stateful Memory Chains）

* **拓扑设计：** 外部上下文注入结构。在生成阶段之前挂载外部检索器或历史会话存储，将动态获取的知识片段或历史消息列表注入提示词上下文。
* **底层实现：** RAG 链通常由“并行透传检索子链 + 提示词模板 + 模型 + 解析器”串联构成；记忆链则通过 `RunnableWithMessageHistory` 包装基础链，在每次调用前后自动根据会话标识读取与持久化消息历史。

### 7. 有环图状态机与智能体链（Graph-based Agentic Chains）

* **拓扑设计：** 当任务需要条件循环、工具多轮调用、自我反思修正或人工审批中断时，线性与有向无环（DAG）链条不再适用，转而采用有向循环图（LangGraph 运行时）。
* **底层实现：** 将每个处理步骤抽象为图节点，把控制流转移抽象为条件边，并引入中心化的持久化状态对象与检查点机制（Checkpointer），使链条具备断点恢复、状态回溯与多智能体协同能力。

## 三、不同链条结构选型对照

| 链条结构 | 拓扑形态 | 执行调度特性 | 核心适用场景 |
| --- | --- | --- | --- |
| **线性串行链** | 直线单向流水线 | 顺序执行，支持端到端流式穿透 | 文本改写、格式提取、单步指令翻译 |
| **并行扇出链** | 一对多菱形聚合 | 线程池 / 协程并发执行，耗时取最大值 | 多源知识库同时检索、多角度同步评估 |
| **透传增量链** | 主干直通 + 旁路加工 | 保留原始输入并增量合并新字段 | 多阶段连续推理、检索结果与原问题拼接 |
| **条件路由链** | 单入口多出口分发 | 顺序评估条件谓词，命中即短路执行 | 客服意图分流、按问题难度路由大小模型 |
| **容错降级链** | 主备冗余包裹 | 异常捕获 + 指数退避重试 + 自动切换备链 | 生产环境高可用保障、多模型厂商兜底 |
| **有环状态图** | 有向循环状态机 | 支持循环迭代、持久化状态与人工介入 | 自主工具调用智能体、多步规划与自我纠错 |
