在 LangChain 中，**自定义 Prompt 模板**的核心目标是把静态指令、动态变量、多轮对话历史或外部上下文解耦为可复用、可校验的 `Runnable` 组件，并无缝接入 LCEL（LangChain Expression Language）链路。

该图展示了用户输入进入链路后，先经过 **Prompt Template** 组装提示词，再交给模型/链执行动作与工具调用，最后经由输出解析器返回结果。

---

### 一、 常见模板类型与适用场景

| 模板类 | 适用对象 | 核心能力 |
| --- | --- | --- |
| `PromptTemplate` | 普通文本模型 / 简单单段提示 | 占位符替换、默认值、变量校验 |
| `ChatPromptTemplate` | 聊天模型（如 `ChatTongyi`、`ChatOpenAI`） | 按角色（`system`、`human`、`ai`）组织消息，支持 `MessagesPlaceholder` 注入历史或工具消息 |
| `FewShotPromptTemplate` / `FewShotChatMessagePromptTemplate` | 需要风格对齐、分类或格式规范的任务 | 动态注入示例库（可配合 `ExampleSelector` 按相似度或长度筛选示例） |
| `PipelinePromptTemplate` / 组合式 LCEL | 多段拼接或模块化提示词 | 将角色设定、背景规则、输出约束拆分为独立片段再组合 |
| 自定义 `BasePromptTemplate` 子类 | 复杂预处理、外部模板引擎（Jinja2 / Mustache）或动态计算逻辑 | 完全掌控 `format_messages` / `format` 渲染过程 |

---

### 二、 实用自定义方式与示例

#### 1. 定制 `ChatPromptTemplate`：角色分工 + `MessagesPlaceholder` + 部分填充

适合多轮对话、Agent 或工具调用场景。通过 `partial` 可以提前固化部分变量（如业务规则、时区或版本号），运行时只传动态参数。

```python
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder

prompt = ChatPromptTemplate.from_messages([
    (
        "system",
        "你是{domain}领域的严谨分析助手。规则：{rules}。当前版本：{version}。",
    ),
    MessagesPlaceholder(variable_name="history", optional=True),
    ("human", "{question}"),
]).partial(
    domain="企业财务",
    rules="只依据提供的上下文或工具结果回答，缺失数据时明确说明",
    version="v1.2",
)

messages = prompt.format_messages(
    history=[("human", "上一季度毛利率是多少？"), ("ai", "当前尚未接入本季度经审计财报。")],
    question="最新的财务数据是什么？",
)

```

#### 2. 定制 `FewShotChatMessagePromptTemplate`：动态少样本示例

当希望模型严格遵循特定输出结构（例如“结论 + 风险点 + 数据来源”）时，可将示例抽离为结构化列表并注入聊天模板。

```python
from langchain_core.prompts import ChatPromptTemplate, FewShotChatMessagePromptTemplate

examples = [
    {
        "input": "营收同比增长 12%，但经营现金流为负",
        "output": "结论：利润质量需关注。\n风险点：应收账款或存货占用增加。\n依据：营收与经营现金流背离。",
    },
    {
        "input": "缺少最新财报披露文件",
        "output": "结论：暂无法给出最新财务指标。\n风险点：无可靠数据源时臆造数字会导致误判。\n依据：当前上下文无披露数据。",
    },
]

example_prompt = ChatPromptTemplate.from_messages([
    ("human", "{input}"),
    ("ai", "{output}"),
])

few_shot_prompt = FewShotChatMessagePromptTemplate(
    example_prompt=example_prompt,
    examples=examples,
)

final_prompt = ChatPromptTemplate.from_messages([
    ("system", "请严格模仿示例格式输出分析结果。"),
    few_shot_prompt,
    ("human", "{input}"),
])

```

#### 3. 继承 `BasePromptTemplate`：完全自定义渲染逻辑

当模板需要读取外部配置、执行自定义校验、拼接动态元数据，或使用非默认语法时，可直接继承 `BasePromptTemplate`（聊天场景可继承 `BaseChatPromptTemplate`）。关键是实现 `input_variables` 属性与 `format_messages` / `format` 方法。

```python
from typing import Any, List
from langchain_core.messages import BaseMessage, HumanMessage, SystemMessage
from langchain_core.prompts import BaseChatPromptTemplate


class AuditedPolicyPromptTemplate(BaseChatPromptTemplate):
    """在渲染阶段自动注入审计声明与必填字段校验的自定义模板。"""

    policy_header: str

    @property
    def input_variables(self) -> List[str]:
        return ["question", "data_status"]

    def format_messages(self, **kwargs: Any) -> List[BaseMessage]:
        question = str(kwargs.get("question", "")).strip()
        data_status = str(kwargs.get("data_status", "unverified")).strip()
        if not question:
            raise ValueError("question 不能为空")

        system_text = (
            f"{self.policy_header}\n"
            f"当前数据状态：{data_status}。若状态非 verified，禁止输出未经核实的数字。"
        )
        return [
            SystemMessage(content=system_text),
            HumanMessage(content=question),
        ]

    def format(self, **kwargs: Any) -> str:
        return "\n".join(m.content for m in self.format_messages(**kwargs))


custom_prompt = AuditedPolicyPromptTemplate(
    policy_header="【合规风控提示词】"
)
chain_input = custom_prompt.invoke({
    "question": "最新的财务数据是什么？",
    "data_status": "pending_api",
})

```

---

### 三、 工程实践要点

* **转义字面量花括号**：模板默认把 `{变量名}` 当作占位符。如果提示词中包含 JSON 示例或字典字面量，需写成 `{{` 和 `}}`，否则会被误识别为缺失输入变量。
* **模板引擎切换**：需要条件分支、循环或更复杂的文本渲染时，可在 `PromptTemplate.from_template(..., template_format="jinja2")` 中指定 `jinja2`（需安装 `jinja2`）。
* **与 LCEL 组合**：所有 Prompt 模板都实现了 `Runnable` 接口，可直接放在 `prompt | model | parser` 链首，也可用 `RunnableLambda` 在进入模板前做清洗或检索注入。
